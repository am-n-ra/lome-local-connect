# Opportunity Source Verification Reference

Use this reference when discovering, sharing, or updating grants, programs, partnerships, pilots, procurements, credits, or capital opportunities. Time-sensitive opportunity data decays quickly; preserve the source and as-of date.

## Source hierarchy

Prefer the issuing institution’s official program page, terms, request-for-proposal, application portal, or direct written confirmation. Use a recognised ecosystem publication only as discovery, then verify against the issuer. Treat social posts, aggregators, reposts, and personal messages as leads—not confirmation.

## Minimum source record

| Field | Required value |
|---|---|
| Opportunity name and issuer | Exact current name and issuing organisation. |
| Official URL / contact | Primary source or explicitly named verified contact. |
| As-of date and time zone | When the facts were checked. |
| Availability | Open, upcoming, rolling, closed, or unknown—only if source-supported. |
| Eligibility | Entity, stage, geography, sector, ownership, revenue, or other relevant requirement. |
| Benefit | Money, credits, pilot, relationship, research, market access, or other stated value. |
| Obligations / exclusions | Cost share, reporting, equity, repayment, IP, exclusivity, data, geography, or time commitment. |
| Deadline / process | Date, time zone, submission method, stages, and known decision timing. |
| Confidence | `verified`, `partially verified`, or `lead only`. |

Do not infer cheque size, acceptance rate, eligibility, operating geography, deadline extension, investment mandate, or decision timeline from a similar program or an old announcement.

## External action boundary

Research and draft preparation may proceed with the user’s instruction. Request explicit confirmation before applying, submitting, uploading sensitive data, booking a commitment-making meeting, accepting terms, signing, or transferring funds.
