# Ecosystem activation manifest

Use this manifest at the beginning of every Founder HQ dispatch. It makes clear that a named route must be verified before Founder HQ can claim that a specialist owns the next gate.

| Request pattern | Primary skill / invocation | Specialist gate | Required return to Founder HQ |
|---|---|---|---|
| Build, design, fix, refactor, migrate, integrate, launch, or extend a product | `/nature-way` | Product phase, contract, vertical slice, proof, and release gate | Resource Receipt; active structural path/phase; evidence; residual gap; owner; next task. |
| Clarify a problem, diagnose venture stage, test demand, distribution, retention, or scale readiness | `/nature-way-venture-lifecycle` | Current-stage and next-proof gate | Resource Receipt; stage scorecard; counter-evidence; distribution next test; owner. |
| Raise capital, prepare investor materials, run diligence, or close financing | `/nature-way-fundraising` | Capital fit, claim, readiness, and process gate | Resource Receipt; capital proof/claim status; next capital gate; owner. |
| Evaluate a grant, program, partner, pilot, procurement, credit, or external path | `/nature-way-opportunity-intelligence` | Source, terms, fit, capacity, and decision gate | Resource Receipt; verification/qualification status; next action or decline. |
| Resolve a capability gap blocking a milestone | `/nature-way-founder-learning` | Response and transfer-evidence gate | Resource Receipt; response choice; transfer proof; next review. |
| Request an explicitly consented private sidereal reflection | `/nature-way-sidereal-reflection` | Consent, privacy, and non-deterministic reflection boundary | Resource Receipt; private grounded prompt/boundary only; factual handoff if needed. |

## Activation decision

Use `activated` only when the named skill is actually available and in control of the primary gate. Use `user invocation required` when the skill exists but the current environment requires the user to invoke it. Use `unavailable` when it cannot be loaded. The latter two statuses stop Founder HQ from performing the specialist work.

## Resource receipt

The active specialist must list the exact references and templates loaded for the requested phase, the template copied/instantiated if applicable, and any required file that could not be loaded. A resource named in a skill but absent from the receipt is not assumed to have been used.
