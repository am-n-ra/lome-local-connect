## Stage-review rules

1. Record what changed the founder’s belief, not only favourable evidence.
2. Use a defined value event for the segment; do not swap metrics after seeing results.
3. State the data/fixture boundary, observation window, and limitations.
4. Advance only when the stage question is answered to the level required by the next commitment.
5. Return to an earlier stage when new evidence invalidates a critical assumption.
