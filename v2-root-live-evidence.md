## Schema coexistence

The branch exposes 26 public V2 tables, including accounts, facilities, companies, products, discovery, verification, wallets, availability, intents, transaction snapshots/events/members, QR, fulfilment, ratings, audit and analytics. The read-only catalog reported 125 public constraints across V2 tables. It also reported the following non-V2 public tables: `geography_columns`, `geometry_columns`, `omni_schema_migrations`, `osm_tiles` and `spatial_ref_sys`.

The coexistence result supports the additive and namespaced posture. It is not a migration-forward proof because this check did not apply the migration or compare a before/after schema snapshot.

## Remaining live proof

The following items remain open: Auth bearer verification with a real authorized session; idempotent first-login account provisioning; migration forward compatibility and preserved-row comparison; live availability persistence with server-side product/facility validation; database-concurrency proof for duplicate mutations; atomic QR replay behavior; protected route HTTP/provider behavior; and browser recovery for refresh, reconnect, expired context and unavailable dependencies.

## Nature Way decision

This evidence advances the Root ledger from static-only to **partial live persistence evidence**. It does not authorize Trunk implementation or production claims. The next Root gate requires either the missing live checks or an explicit `manual`, `blocked` or `deferred` owner for each one.
