## History and rationalité

- **État avant NW-13g (scoping):** `activateFacilityPro` créait un entitlement 30 j avec `renewal_opt_in=false`, **aucun job d'auto-renew**, aucun toggle UI, aucun rappel, et **`commercial_plan='pro_expired'` n'était jamais posé côté serveur** (gap = la transition d'expiration n'était pas observable/véridique). Le champ `renewal_opt_in` existait déjà sur `v2_facility_entitlements` (migration 009) mais restait inutilisé.
- **Étapes NW-13g:** migration 047 (audit `v2_facility_renewal_runs`), repo (`getFacilityRenewalStatus` plan véridique + `setFacilityRenewalOptIn` + `renewFacilityPro` spend/entitlement/audit; `getWalletOverview` requête + mapping mis à jour — plan dérivé de l'entitlement actif + `commercial_plan='pro_active'` posé côté serveur; bloc stale corrigé), HTTP (3 routes owner), client/types (3 fonctions + types + `WalletFacilitySummary` étendu), UI (carte renouvellement SellerV13 + wallet sheet), tests (repo 8, http 1, api 3), preuve DB branche temp, docs.
- **Honnêteté:** le renouvellement réutilise le kind existant `facility_pro_spend` (pas de nouveau WalletEntryKind) avec la référence `facility-pro-renew:{facilityId}:{period}` — idempotent par période. La dérivation du plan est **véridique** (entitlement actif vs expiré) et jamais un champ figé : quand le solde manque, l'audit `insufficient_funds` est écrit, la facilité reste `pro_expired`, et l'UI montre le rappel. La preuve canonique (apply migration 047 + preuve live sur données réelles) attend un **ordre fondateur** (même règle T-07d que 046/le push prod).
- Suite monte **380 → 393 tests** (+8 repo renewal, +1 http WalletPolicyError renewal, +3 api renewal).
- Barème (D-J): Pro vendeur = **10 $ = 5 000 XOF/mois** (prix `pro_price_minor` DEFAULT 1000 = 1 000 XOF/mois pilote; le repo expose `proPriceMinor`/`billingCurrency` pour affichage véridique). Le `renewal_opt_in` reste **désactivé par défaut** (aucun renouvellement silencieux); le rappel avant expiration est exposé par la carte UI (`jours restants` + alertes) — un vrai job de rappel asynchrone est hors scope P1 (watch Gate 7).
