## History and rationalité

- La tranche NW-13e était principalement **prête en code** (`qualifying_sales`/`bonus_unlocked_at`/`unlockFacilityBonus`/grant 10000) mais le **comptage « users distincts » exigé par D-H était absent** : l'incrément `qualifying_sales + 1` par transaction fermée comptait les achats répétés du même buyer. La migration 046 apporte la **source de vérité** (table trace + objet `seller_unlocks`) et le CTE réécrit garantit le minimum entre le nombre d'acheteurs distincts et 3.
- **Étapes NW-13e:** migration 046 (v2_seller_unlock_progress + v2_seller_unlocks), repo (`submitTransactionRating` → distinct; `getFacilityBonusStatus`; `unlockFacilityBonus` marque granted), HTTP (2 routes owner), client/types (bonus), UI (bandeau SellerV13), tests, preuve DB branches temp, docs.
- **Honnêteté:** le grant `bonus_grant 10000` (10 000 XOF = 20 $ au taux repo ~500 XOF/USD) était déjà câblé avant NW-13e dans `submitTransactionRating`/`unlockFacilityBonus`; ce que NW-13e change est la **condition d'éligibilité users distincts** et l'**exposition statut UI/HTTP**. La preuve canonique sur la branche `br-dawn-hill-am5amy22` (apply migration 046 + preuve live sur données réelles) attend un **ordre fondateur** (même règle T-07d que le push prod).
- Suite monte **375 → 380 tests** (+2 repo `getFacilityBonusStatus` + 1 http WalletPolicyError + 2 api bonus − 2 tests rating adaptés).
- **Correction montant (retour fondateur 2026-09-13):** le bonus n'est pas « 2000 XOF » — le fondateur précise le barème **20 $ seller bonus confiance / 10 $ seller Pro / 5 $ buyer Pro**. Le repo fixe déjà l'ancrage 20 $ = 10 000 FCFA (`V0_SELLER_REWARD_FCFA`, taux ~500 XOF/USD) et D-J verrouille « Pro vendeur 5 000 XOF/mois » = 10 $. **Correction appliquée**: `amount_minor` bonus 2000 → **10000 XOF** (migration 046 + repo `bonus_grant` + types + tests + bundles serverless); le nom d'objet `pro_test_credit_20_usd` et l'UI « 20 USD » restent inchangés. Preuve DB refaite sur branche fraîche `br-polished-bread-amflohl0` (T1-T5 + montant 10000 vérifié, cleanup 0). Barème Pro vendeur 10 $ / acheteur Pro 5 $ = tranches NW-13g/NW-13h à venir (pas de code bonus ici).
